# aribulan.com

## Numberfall

An original mobile-first arithmetic army runner by emr, prepared for `/numberfall/`. It includes 24 campaign stages, daily and endless modes, device-local progress, optional sound, and offline support, with no ads or payments.

See [game documentation](numberfall/README.md) for local preview, controls, validation and publication instructions, and [research notes](numberfall/RESEARCH.md) for the reference-game findings. The game is being reviewed before publication; the existing homepage is unchanged.
